# Interview Question Repository

A collection of Java interview questions organized by topic. This repository contains solutions and explanations for common coding interview problems.

## 📁 Contents

- **ArrayQuestion** - Array manipulation and algorithm problems
- **StringQuestion** - String processing and manipulation problems
- **TrickyQuestion** - Edge cases and tricky coding problems

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/0harshitsingh1/Interview_Question.git
   cd Interview_Question
   ```

2. Navigate to the topic of interest and review the Java implementations

## 💡 Topics Covered

- Array operations and algorithms
- String manipulation techniques
- Tricky interview questions to test problem-solving skills

## 📝 How to Use

Each directory contains Java solution files for different problems. Review the code, understand the logic, and practice implementing similar problems.
